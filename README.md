# COLDEX-ECM-data

Summary
-------
This repository contains ECM data from COLDEX Allan Hills ice cores, processing scripts, and plotting utilities used to analyze and visualize the datasets produced by COLDEX experiments.

File structure
--------------
- **data/**  _Raw and cleaned ECM data files organized by sample/experiment. Top-level subfolders include `not-cleaned/` and `clean/`._
  - **data/not-cleaned/**  _Original unprocessed exports and raw text/CSV files. Per-sample folders (e.g., `ALHIC2301/`) contain the raw ECM outputs, text clippings, or instrument exports._
  - **data/clean/**  _Curated and cleaned data files that have been processed into a standard, analysis-ready format (often averaged or re-formatted). These are the recommended inputs for the plotting scripts._
  - **data/<sample>/**  _Each sample/experiment has its own subfolder (e.g., `ALHIC2201`, `ALHIC2302`) containing that run's raw or cleaned measurements._

- **scripts/**  _Python scripts and Jupyter notebooks used to process data and generate figures. Key subfolders:_
  - **scripts/core_scripts/**  _Core utilities and helper modules for data parsing, the ECM class implementation, and reusable functions (e.g., [ECMclass](/Users/Liam/Desktop/UW/ECM/COLDEX_ECM/COLDEX-ECM-data/scripts/core_scripts/ECMclass.py:1))._
  - **scripts/plotting/**  _Plot generation scripts and example notebooks. Includes `basic_plots.py` and notebooks like `basic_plots.ipynb` that demonstrate common visualizations._
  - **scripts/proccessing/**  _Notebook-based helpers for data reformatting and one-line averaging. Note: directory name is spelled `proccessing` in the repository._

- **figures/**  _Outputs from the plotting scripts organized by plot type and sample._
  - **figures/basic_plots/**  _Individual plots per sample and channel generated by `basic_plots.py`._
  - **figures/average_oneline/**  _Summary / averaged oneline plots for each sample (one-per-sample overview images)._

- **environment.yml**  _Conda environment specification (name: `COLDEX_ECM`). Use this to recreate the Python environment used for analysis._
- **LICENSE**  _Project license file._
- **.gitignore**  _Git ignore rules._
- **README.md**  _This file._
- **.vscode/**  _Editor settings and optional workspace configuration._

Notes
-----
- Many per-sample data and figure folders are present (e.g., `data/not-cleaned/ALHIC2302/`, `figures/basic_plots/ALHIC2301/`). Use the file system or `ls` to inspect specific sample contents.
- The repository contains some macOS `.DS_Store` artifacts; they can be ignored or removed locally if desired.

If any of the above folders/files are missing or have different contents on your copy, please inspect the repository root for the exact layout.

Quick start / Instructions for use
---------------------------------
1. Clone the repository:

   git clone <repo-url>
   cd COLDEX-ECM-data

2. Create and activate the conda environment (recommended):

   conda env create -f environment.yml
   conda activate COLDEX_ECM

   Notes:
   - The environment file declares `name: COLDEX_ECM` and a prefix; adjust as needed if you prefer a different environment name or location.
   - If conda is not available, recreate the environment using your preferred Python package manager. The `environment.yml` lists the required packages and Python version (3.13.x).

3. Run processing scripts or notebooks:

   - To run the basic plotting script from the command line:
     python scripts/plotting/basic_plots.py

   - To open notebooks, launch JupyterLab or Jupyter Notebook from the activated environment so that kernels match:
     jupyter lab

   - Processing utilities are in `scripts/core_scripts/` (for example, [ECMclass](/Users/Liam/Desktop/UW/ECM/COLDEX_ECM/COLDEX-ECM-data/scripts/core_scripts/ECMclass.py:1)).
